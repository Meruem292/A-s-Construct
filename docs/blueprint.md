# **App Name**: ConstructView

## Core Features:

- Service Showcase: Display construction services offered with descriptions and images, showcasing expertise.
- Automation Portfolio: Showcase automation projects with detailed descriptions, images, and video demonstrations to highlight capabilities.
- Image Gallery: Dedicated gallery for project images, allowing users to browse completed works and visualize potential outcomes.
- Contact Form: A straightforward form for potential clients to request quotes or information, facilitating easy communication.

## Style Guidelines:

- Primary color: Dark grayish yellow (#B3A125) evoking construction equipment.
- Background color: Light grayish yellow (#F5F3E5) maintaining visual consistency and a light atmosphere.
- Accent color: Strong orange (#D97D21) to draw attention to key interactive elements.
- Headline font: 'Belleza' sans-serif for a fashionable and artful presentation of titles and key phrases. Note: currently only Google Fonts are supported.
- Body font: 'Alegreya' serif for readability and an elegant touch in detailed descriptions. Note: currently only Google Fonts are supported.
- Use simple, modern line icons to represent different services or project types.
- Employ a grid-based layout to showcase projects in a visually appealing and organized manner.
- Subtle fade-in and slide-up animations when projects or services come into view to enhance user engagement.
